# Exploratory Data Analysis Assignments

A collection of data science projects focused on exploratory data analysis (EDA) using Python. This repository contains three comprehensive data analysis assignments covering entertainment, mobile apps, and open-source software development.

## 📊 Projects Overview

### 1. [Investigating Netflix Movies and Guest Stars in The Office](./investigating-netflix-movies-and-guest-stars-in-the-office)
Analyzes Netflix movie data to investigate whether movie durations are declining over time. The project explores trends from 2011-2020 and examines how different genres (Children's content, Documentaries, Stand-Up) influence average movie duration.

**Key Technologies**: pandas, matplotlib  
**Key Skills**: Data filtering, trend analysis, data visualization

---

### 2. [The Android App Market on Google Play](./the-android-app-market-on-google-play)
Comprehensive analysis of 10,000+ Android apps from Google Play Store. Explores app categories, ratings, pricing strategies, and user sentiment to derive actionable insights for app development and marketing.

**Key Technologies**: pandas, numpy, matplotlib, seaborn, plotly  
**Key Skills**: Data cleaning, statistical analysis, sentiment analysis, business insights

---

### 3. [The GitHub History of the Scala Language](./the-gitHub-history-of-the-scala-language)
Analyzes the development history of the Scala programming language using Git and GitHub data. Identifies contribution patterns, key contributors, and project health metrics over a 7-year period.

**Key Technologies**: pandas, matplotlib  
**Key Skills**: Time series analysis, version control data mining, community analysis

---

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/yourusername/exploratory-data-analysis.git
cd exploratory-data-analysis
```

### 2. Set Up Virtual Environment (Recommended)
```bash
# Create virtual environment
python -m venv .venv

# Activate virtual environment
# On Windows:
.venv\Scripts\activate
# On macOS/Linux:
source .venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install pandas numpy matplotlib seaborn plotly jupyter
```

### 4. Launch Jupyter Notebook
```bash
jupyter notebook
```

Navigate to any project folder and open the corresponding `.ipynb` file to explore the analysis.
